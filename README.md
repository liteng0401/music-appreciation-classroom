# 高中音乐鉴赏 · 互动课堂教学网页

人音版《普通高中教科书·音乐·必修·音乐鉴赏》（2019 年版）的互动教学网页，供音乐教师在课堂上直接打开使用。

## 功能
- 按 **序篇 / 上篇（第一—八单元）/ 下篇（第九—十八单元）** 导航，每单元一页
- 每单元含：**本节要点 · 核心框架/概念 · 关键术语 · 鉴赏思路 · 作品鉴赏 · 聆听示范 · 学习要点**
- **随堂练习**：选择题 + 判断题，提交即显对错与解析，顶部进度条，按单元计分
- **术语速查**：全书 113 条术语，可搜索
- **对比速查**：民歌/乐种/京剧行当/西方史期/曲式/歌剧/爵士等速查表
- 浅色/深色主题切换，适配投影仪；纯前端、可离线打开

## 使用
直接用浏览器打开 `index.html` 即可（无需联网、无需服务器）。
如需在线分享，把本仓库部署为静态站点即可。

## 文件
- `index.html` — 网页主体（自包含）
- `data.js` — 由章节自动生成的结构化数据（含练习题），运行 `generate_data.py` 可重新生成
- `generate_data.py` — 从 `~/.workbuddy/skills/music-appreciation/` 解析生成 `data.js`
