# 高中音乐鉴赏 · 互动课堂教学网页

人音版《普通高中教科书·音乐·必修·音乐鉴赏》（2019 年版）的互动教学网页，供音乐教师在课堂上直接打开使用。

## 功能
- 按 **序篇 / 上篇（第一—八单元）/ 下篇（第九—十八单元）** 导航，每单元一页
- 每单元含：**本节要点 · 核心框架/概念 · 关键术语 · 鉴赏思路 · 作品鉴赏 · 拓展聆听 · 配套资源下载 · 聆听示范 · 学习要点**
- **随堂练习**：选择题 + 判断题，提交即显对错与解析，顶部进度条，按单元计分
- **术语速查**：全书 113 条术语，可搜索
- **对比速查**：民歌/乐种/京剧行当/西方史期/曲式/歌剧/爵士等速查表
- 浅色/深色主题切换，适配投影仪；纯前端、可离线打开
- **校本品牌与便签**：侧栏显示河北峰峰第一中学校徽；右下角 📝 全局悬浮便签，上课随手记校本补充，仅存本机浏览器
- **作品音频播放**：每首作品卡片带「▶ 播放」按钮（有音频才显示），点击即播；底部悬浮播放条显示曲名、可停止
- **🎧 拓展聆听（选听）**：教材「拓展与探究」里未列入正文曲目表的音频，按课本编号归入对应单元，同样可点播
- **📎 配套资源下载**：每单元列出配套的 PPT 课件与教案 Word，显示文件名与体积，点击即下载

## 使用
- **公网在线打开**：https://liteng0401.github.io/music-appreciation-classroom/ （GitHub Pages，仓库已公开）
- 也可直接双击本地 `index.html` 打开（纯前端、可离线，无需联网、无需服务器；但音频与 PPT 下载需在线或本地文件齐全）。

### 两套 PPT 的区别（重要）
| | 位置 | 份数/体积 | 说明 |
|---|---|---|---|
| **网盘原版课件** | Release 附件区 `ppt-v1` | 52 份 / 2.0 GB | 网上搜集的人音版配套课件原件，**未经压缩**。网页「📎 配套资源下载」里点按钮即从此处下载 |
| **本项目自制课件** | 仓库 `ppt/` 目录 | 35 份 / 3.1 MB | 由 `generate_ppt.py` 生成，含变易教学设计的四图式、随堂练习，体积小、便于二次编辑 |

> Release 附件名被 GitHub 强制改成纯 ASCII（中文会被吞掉），故统一编号为 `<单元>-<序号>.pptx`（如 `ch04-02.pptx`），与网页条目顺序一一对应；网页上仍显示中文文件名。

## 文件
- `index.html` — 网页主体（自包含）
- `data.js` — 由章节自动生成的结构化数据（含练习题），运行 `generate_data.py` 可重新生成
- `generate_data.py` — 从 `~/.workbuddy/skills/music-appreciation/` 解析生成 `data.js`
- `audio.js` — 音频映射表（`"单元id|曲名"` → `audio/<单元>/<文件>.mp3`），由 `import_resources.py` 生成
- `audio_extra.js` — 「拓展聆听」映射表（`window.AUDIO_EXTRA`：单元 → 曲名/路径列表），同上生成
- `resources.js` — 配套资源清单（`window.RESOURCES`：单元 → PPT/教案的显示名、体积、下载链接），同上生成
- `ppt_urls.json` — PPT 附件名 ↔ 原始文件名 ↔ Release 下载链接，由 `publish_ppt.py` 生成
- `audio/` — 各单元作品音频（`.mp3`，192 kbps，共 87 首 + 拓展聆听 13 条）
- `media/jiaoan/` — 各单元教案 Word（33 份）
- `media/ppt/` — 各单元 PPT 原件（52 份 / 2.0 GB），**已 gitignore**，只作为上传 Release 的本地源
- `school-logo.png` — 学校官方校徽（彩色 logo，140×140，白底）
- `school-name.png` — 学校官方校名标（河北峰峰第一中学 + 英文名，356×96，白底）
- `school-badge.png` / `school-badge-display.png` — 早期使用的单色金色字标（已弃用，保留备用）
- `generate_ppt.py` — 由章节自动生成每节 PPT 课件（python-pptx），输出到 `./ppt`
- `ppt/` — 本项目自制的每节上课用 PPT 课件（35 份）
- `import_audio.py` — 音频匹配的核心逻辑（曲名归一化 + 二元组相似度打分 + `OVERRIDE` 手工兜底表），被 `import_resources.py` 复用
- `import_resources.py` — **主导入脚本**：扫描素材目录，把 音频MP3 → 作品、拓展音频 → 单元、PPT/教案 → 单元，拷贝到 `audio/` 与 `media/`，并生成上述三个 js
  - 用法：`python3 import_resources.py --dry`（只看对应关系与缺口）/ 去掉 `--dry` 实际执行
- `publish_ppt.py` — 把 `media/ppt/` 下 52 份课件作为 GitHub Release 附件发布（自动改名为 ASCII 编号、分批上传）
  - 用法：`python3 publish_ppt.py --plan`（只生成 `ppt_urls.json`）/ `--upload`（建 release + 上传）

### 素材来源与匹配规则
- 素材源：网盘「人音版 素材」下的三套目录 —— 音频 mp3（100 个）、课件 PPT（52 个）、教案 word（33 个）。
- 音频匹配：按曲名归一化后算二元组相似度（阈值 70 分），`import_audio.py` 里的 `OVERRIDE` 表处理自动匹配不到的（如《费加罗的婚礼》序曲，源文件名仅为 `85.序曲.mp3`）。
- 拓展音频归属：MP3 文件名带教材流水号，按「最后一个已结束的单元」规则推断归属，归入 `audio_extra.js`。
- 已知缺口：**《马太受难曲》**（第十二单元 巴赫）在素材里没有音频；**`思念.pptx`、`粤剧荔枝颂的唱功--子喉.pptx`** 两个课件不属于课本正文单元，暂未挂到网页。
- 版权：录音与课件版权归原出版方/表演者所有，仅供课堂教学参考。
